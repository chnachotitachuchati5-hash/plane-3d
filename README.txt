เจ็ทโดยสาร — เว็บ 3D เครื่องบิน
================================

เปิดไฟล์ index.html ใน Chrome / Edge / Firefox (แนะนำผ่านเซิร์ฟเวอร์เล็ก ๆ)

  python3 -m http.server 8766 --directory .

แล้วเปิด http://127.0.0.1:8766/

ถ้าไม่มีเน็ต ให้เติม ?offline=1 หรือปล่อยให้หน้าเว็บสลับไปใช้ไฟล์ใน vendor/ เอง
เมื่อ CDN โหลดไม่สำเร็จ

วิธีเล่น
- ลากเพื่อหมุนกล้อง ใช้สองนิ้วหรือลูกลิ้งเพื่อซูม
- ปุ่มมุมกล้อง: มุมเฉียง, ด้านข้าง, ด้านบน, ห้องนักบิน
- ปุ่ม: หมุนอัตโนมัติ, เปิด/ปิดไฟ (ไฟนำทาง ไฟลงจอด และไฟกระพริบ)
- คลิกหรือชี้ที่ชิ้นส่วน เพื่อดูชื่อและเกร็ดวิทยาศาสตร์ภาษาไทย
- พัดลมเครื่องยนต์หมุน และลำตัวโอนเอียงเบา ๆ ราวกับกำลังบิน
